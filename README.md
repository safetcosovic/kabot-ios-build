# Mudpup – iOS build

Build-only repository for **Mudpup: Offroad Rescue** (iOS, `com.mudpup.offroad`).
It holds the Capacitor iOS project with the already-built, minified game bundle and GitHub Actions workflows that
archive the app on macOS (every push) and upload a signed build to App Store Connect (manual run).
The game's source code is kept in a private repository.
