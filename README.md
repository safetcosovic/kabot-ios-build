# Kabot – iOS build

Build-only repository for **Kabot: Robot Smash Shooter** (iOS, `com.kabot.smash`).
It holds the Capacitor iOS project with the already-built, minified game bundle and a GitHub Actions
workflow that archives the app on macOS and uploads it to App Store Connect (TestFlight).
The game's source code is kept in a private repository.
